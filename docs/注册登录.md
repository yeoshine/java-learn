可以，按这个顺序测最方便。假设项目启动在 `http://localhost:8080`。

先注册：

```bash
curl -X POST "http://localhost:8080/api/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "demo",
    "email": "demo@test.com",
    "password": "123456"
  }'

{"success":true,"message":"注册成功","data":{"token":"eyJhbGciOiJIUzM4NCJ9.eyJzdWIiOiJkZW1vIiwiaWF0IjoxNzc2MzI3NDk0LCJleHAiOjE3NzY0MTM4OTR9.N_rzoTmhiFEjG-tbGXaFVDbD7sAjEO8ThP15L-yPajH8_F41hKz51LcpvU9AIbMM","tokenType":"Bearer","username":"demo","email":"demo@test.com"}}
```

再登录：

```bash
curl -X POST "http://localhost:8080/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "demo",
    "password": "123456"
  }'

  {"success":true,"message":"登录成功","data":{"token":"eyJhbGciOiJIUzM4NCJ9.eyJzdWIiOiJkZW1vIiwiaWF0IjoxNzc2MzI3NTEzLCJleHAiOjE3NzY0MTM5MTN9.zNZh1iDH9Zr7D4jz9NbakNxwM-TIb6Gc0lPXmeu_h7GxF3Ph5OZZmYvIqELht82b","tokenType":"Bearer","username":"demo","email":"demo@test.com"}}
```

登录成功后，返回里会有 `token`，然后拿这个 token 请求用户信息：

```bash
curl "http://localhost:8080/api/users/me" \
  -H "Authorization: Bearer 这里替换成登录返回的token"

  {"success":true,"message":"获取当前用户成功","data":{"id":1,"username":"demo","email":"demo@test.com","createdAt":"2026-04-16T16:18:15"}}
```

如果你想直接在 Postman 里测，对应接口是：

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/users/me`

请求体字段要求和代码一致：
- 注册：`username`、`email`、`password`
- 登录：`username`、`password`
